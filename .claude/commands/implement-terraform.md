# /implement-terraform <機能名>

**引数:** 機能名 (例: `/implement-terraform CloudWatchアラーム`)

---

## ステップ0: 状態確認（再入チェック）

`.steering/` 配下から引数の機能名に対応するディレクトリを探す。

- **見つからない場合**: `/plan-terraform <機能名>` を先に実行するよう案内して終了する。
- **見つかった場合**: `tasklist.md` を読み込む。

未完了タスク（`[ ]`）の数を確認する。

- **0件（全て `[x]`）**: 実装完了済み。`/ship-terraform <機能名>` に進むよう案内して終了する。
- **1件以上**: 実装ループを開始する。

---

## ステップ1: 実装ループ

`Skill('development-guideline-terraform')` のコーディング規約を遵守して実装する。
テストファイル（`.tftest.hcl`）を作成・修正する場合は `Skill('terraform-test-patterns')` を参照する。

以下を未完了タスクがなくなるまで繰り返す:

1. `tasklist.md` の先頭にある未完了タスク（`[ ]`）を1つ特定する
2. そのタスクを実装する
3. 実装完了後、`Edit` ツールで `tasklist.md` の該当行を `[ ]` → `[x]` に更新する
4. 1. に戻る

---

## 例外処理ルール

**タスクが大きすぎる場合**
サブタスクに分割して `tasklist.md` を更新し、ループを継続する。

**技術的理由でタスクが不要になった場合のみスキップ可**

```
- [x] ~~タスク名~~ (理由: 具体的な技術的理由)
```

**絶対禁止**
- 理由なくタスクをスキップする
- 未完了タスクを残したままループを終了する
- ユーザーに判断を仰ぐ

---

## ステップ2: 完了後

全タスクが `[x]` になったら以下を案内する:

```
実装が完了しました。
検証・リリースを行うには: /ship-terraform <機能名>
```
